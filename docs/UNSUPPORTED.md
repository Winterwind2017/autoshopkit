# 做不到 / 别试

按"为什么做不到"分类，避免下次再撞。能做的见 `CAPABILITIES.md`。

## A. 硬件/授权不在，本仓库不承诺

| 能力 | 现状 | 说明 |
| --- | --- | --- |
| 在线监控读数（`monitor` 真值） | **未闭环** | 需要真实 PLC 连接；离线调试端口在部分机型上是空实现 |
| 真正下载到 PLC | **未闭环** | 只做到"生成离线下载文件"（`生成下载文件` → 下载选项 → 生成文件 → Shell 另存为）；下载本身要连机与授权 |
| 强制/解密客户工程密码 | **不做** | 与容器编解码无关，属于绕过授权 |

## B. 界面层面做不到

| 能力 | 原因 |
| --- | --- |
| 写 H5U 梯形图程序 | H5U 文档只有一个自绘 `AfxFrameOrView90u`，`查看→指令表` 无效，全进程 `Scintilla` 数为 0；写入通道只对 H3U 成立 |
| 从界面读 H5U 程序文本 | 同上；H5U 的读法是编译产物 `il_log.log`（`autoshopkit illog`） |
| 用 UIA 点梯形图画布 | 画布没有子元素，只能盲点 + 键盘，风险不可接受 |
| 网格数据整块导出 | 网格是 `VSFlexGrid8N`，无剪贴板导出；只能逐格读（点格 + F2） |
| 无弹窗地跑工程级命令 | 工程若引用了本机缺失的 EtherCAT ESI，编译/导入/导出每次都会弹模态框；关掉会再弹 |

## C. 文件格式还没解完

| 项 | 现状 |
| --- | --- |

## D. 环境坑（不是能力问题，但会让判据骗人）

- **两个测试套件不能并行**：抢同一个 AutoShop 实例 → `COMError 事件无法调用任何订户`。
- **`.hcp` 被打开期间独占锁**：读文件前先 `autoshopkit stop`。
- **DPI**：内/外进程 awareness 不一致时，UIA 给物理矩形、SendInput 用逻辑坐标，差 1.5 倍。
- **H5U 工程树是 cid=2**：cid=1 是器件目录（877 项）。用 `app.tree()`，别自己按 cid 取。
- **EtherCAT ESI 缺失**：`EtherCat.dat` 里配了从站但本机没有对应 XML 时，
  每个工程级命令都会弹一次模态框；此时编译/导入/导出都不可用（读出树和文件仍然可以）。
